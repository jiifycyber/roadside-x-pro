ROADSIDE X V17+ COMMUNITY & PROVIDER NETWORK

1. Back up the current project lib folder.
2. Copy this package's lib folder into the Flutter project root.
3. Run:
   flutter clean
   flutter pub get
   flutter run -d chrome

The local community interface works with demonstration data. Real accounts, posts,
messages, groups, marketplace media, notifications, verification, and moderation require
the backend described in backend/V17_COMMUNITY_BACKEND_BLUEPRINT.md.
