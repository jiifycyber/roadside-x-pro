# Roadside X V18 Futuristic Design System

## Visual language
- Deep-space navy background with cyan, violet, magenta, and green energy accents.
- Glass panels use blur, translucent gradients, fine neon borders, and controlled glow shadows.
- Selected navigation items appear as floating illuminated capsules.
- Critical status is communicated with animated pulse indicators.

## Accessibility
- Text remains high-contrast.
- Glow is decorative and never the only status signal.
- Responsive layouts remain compatible with phone, tablet, desktop, and web.
- Motion is short and UI-focused; production builds can add a reduced-motion preference.

## Production recommendations
- Add a user preference for glow intensity and animation reduction.
- Test lower-powered Android devices before enabling heavier blur everywhere.
- Use image assets sparingly; the V18 system is mostly vector and shader based.
