ROADSIDE X V11 ENTERPRISE EDITION

INSTALL
1. Back up the current Flutter lib folder.
2. Replace it with the lib folder in this package.
3. Keep/add the packages in PUBSPEC_ADDITIONS.yaml.
4. Run:
   flutter clean
   flutter pub get
   flutter run -d chrome

IMPORTANT
The local V11 modules work without app-store accounts. Secure multi-device logins,
real-time cloud sync, true AI, push notifications, SMS/email, telematics, payments,
and live motor-club integrations require approved external services and credentials.
Never place API secrets directly in Flutter source code.
