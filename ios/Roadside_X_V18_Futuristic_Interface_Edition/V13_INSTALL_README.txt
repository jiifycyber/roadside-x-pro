ROADSIDE X V14 AI CALL CENTER EDITION

INSTALL
1. Back up the current Flutter lib folder.
2. Copy this package's lib folder into the Flutter project root.
3. Ensure the dependencies in PUBSPEC_ADDITIONS.yaml are present.
4. Run:
   flutter clean
   flutter pub get
   flutter run -d chrome

V14 LOCAL FEATURES
- AI call-center dashboard
- Call transcript and note intake
- Structured job-detail extraction demo
- Dispatcher approval workflow
- Human escalation workflow
- Automation and safety controls
- Voice-provider connection profiles
- Call audit timeline
- All V12, V11, V10, and V9 screens

LIVE AI PHONE ANSWERING REQUIRES
- A real telephone/voice provider
- Public HTTPS backend
- Voice webhooks and credentials
- Speech transcription
- AI model connection
- Cloud database and secure authentication
- Compliance review for call recording, consent, privacy, and emergency escalation

The Flutter package does not by itself answer a real telephone number. It provides the app workflow and production connector blueprints needed for that integration.
