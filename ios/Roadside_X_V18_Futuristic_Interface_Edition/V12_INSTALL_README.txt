ROADSIDE X V12 ADVANCED AI OPERATIONS

INSTALL
1. Back up the current Flutter lib folder.
2. Copy this package's lib folder into the Flutter project root.
3. Copy dependencies from PUBSPEC_ADDITIONS.yaml into pubspec.yaml if missing.
4. Run:
   flutter clean
   flutter pub get
   flutter run -d chrome

V12 LOCAL FEATURES

PRODUCTION CONNECTIONS REQUIRED
True conversational AI, voice transcription, live traffic, cloud forecasting,
shared employee accounts, multi-device GPS, automated communications, payments,
and live motor-club integrations require a secure backend and approved credentials.
Never place production API keys directly in Flutter source code.
