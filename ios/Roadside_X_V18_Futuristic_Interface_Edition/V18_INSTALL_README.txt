ROADSIDE X V18 — FUTURISTIC INTERFACE EDITION

V18 keeps the complete V17+ feature set and adds a redesigned visual system:
- Floating glass navigation rail
- Neon glow buttons and cards
- Holographic gradient headings
- Animated status indicators
- Responsive sci-fi grid background
- Futuristic login and technician portal
- Glassmorphism across existing SectionCard and MetricCard components
- High-contrast command-center color system

INSTALL
1. Back up the active lib folder.
2. Copy this package's lib folder into the Flutter project root.
3. Keep the dependency packages already used by V17+.
4. Run:
   flutter clean
   flutter pub get
   flutter run -d chrome

V18 is a visual and interaction upgrade. It preserves all existing V17+ local workflows and backend blueprints.
